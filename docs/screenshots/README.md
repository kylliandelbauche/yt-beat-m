# Captures de démonstration

Captures du vrai frontend Beat m sur une instance isolée : bibliothèque fictive, profils Nova / Ryo / Luna, pochettes géométriques originales générées pour cette démonstration et audio synthétique des fixtures de test.

Aucun compte, fichier personnel, chemin local ou média YouTube n'est montré. Les titres, informations musicales et liens d'exemple ne représentent pas le catalogue de l'utilisateur. Les données et le serveur sont temporaires ; aucune bibliothèque courante n'est modifiée.

Les captures et pochettes originales de cette démonstration sont distribuées sous la licence MIT du dépôt. Les polices gardent leurs licences propres.
