# Mes sons — tags communs (#98)

Référence relue le 5 novembre 2026 : [Paper Officiel Mes sons](https://app.paper.design/file/01M5QR97GBV3NSMTMD9TXHX51N/p-H-0), SON-FP-01 et ses groupes de tags ; tokens `9da92004`. Réglages REG-06 conserve sa liste et ses actions, sans nouvelle colonne.

Le schéma 8 ajoute uniquement `song_catalog_tags(song_id, tag_id, position)`, avec clés étrangères et suppression des associations en cascade. Les sauvegardes et transactions de migration existantes s'appliquent ; aucun média n'est déplacé. Les tags hérités sont calculés depuis la prod actuelle. Les réponses son exposent une union de `{id, label, direct, inherited}`, sans copier les associations de la prod.

Créer/modifier reçoit `tag_ids` pour les sélections existantes, `new_tags` pour les créations en brouillon et `recreate_tags` pour les recréations explicites. Les trois listes sont bornées à 120 ; leur union directe aussi. Dans un PATCH, créations/recréations exigent `tag_ids` explicite. Un identifiant supprimé échoue avec conflit, même si son ancien libellé a été recréé sous une autre identité. Les anciens noms de nouveaux tags passent par le registre commun d'alias/suppressions. L'unique transaction valide les champs, les tags et leurs associations ; un échec ne crée aucun orphelin. Omettre les champs tags préserve les associations, notamment lors des actions immédiates d'état/favori.

Recherche : chaque terme correspond au titre ou à un tag direct/hérité, sans casse ni accents. Le filtre répété `tag_ids` est un OU dans cette catégorie et un ET avec les autres filtres ; `tag_missing` inclut les sons sans aucun tag. Les compteurs `beat_count` restent des prods ; `song_count` compte séparément les sons directs ou héritiers, une seule fois. Ils sont précisés dans l'infobulle existante des réglages sans changer la géométrie.

La fiche réserve deux groupes de 44 px, espacés de 8 px : badges hérités bordés (24 px, rayon 7, padding horizontal 10), directs pleins, une ligne défilante par groupe. Le + de 28 px demeure fixe à droite, avec son espace réservé en lecture comme en édition. Un tag des deux origines apparaît uniquement dans le groupe hérité, avec mention « Prod + son » ; sa sélection directe reste accessible dans le sélecteur. Changer/retirer la prod renouvelle l'aperçu hérité et garde les tags directs. Les tags hérités se corrigent via la fiche de prod.

Sélectionner/créer n'enregistre rien avant le Save commun. Annuler rétablit le brouillon enregistré. Les mutations globales rechargent la galerie et la fiche en lecture ; une fiche en édition conserve son brouillon et bénéficie des contrôles de concurrence. Dimensions, focus et lecteur persistent. Les recettes utilisent une bibliothèque temporaire et des médias synthétiques ; aucune migration de la collection personnelle pour les tests.
